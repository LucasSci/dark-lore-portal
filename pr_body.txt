💡 What: Batched thousands of individual `PIXI.Graphics` objects (used for interactive grid cells and fog of war) into two single `Graphics` objects (`batchedCells` and `batchedFog`). Interaction is now handled by a single pointer event listener that calculates the clicked cell coordinates.
🎯 Why: Instantiating thousands of individual `Graphics` objects and their associated event listener closures during the render cycle causes massive Garbage Collection (GC) overhead, memory bloat, and significant rendering lag.
📊 Impact: Eliminates the allocation of O(N) `Graphics` objects per render (where N is the number of grid cells). Significantly reduces GC spikes, memory usage, and improves frame rate during board updates. The O(N) lookup during a user click is a negligible cost compared to the render savings.
🔬 Measurement: Verify by rendering a large map with fog enabled. The initial render time, memory usage, and frame rate during token movement should be noticeably improved with fewer dropped frames caused by GC pauses.
